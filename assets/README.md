# Recursos opcionales

- `audio/halloween.mp3`: música. Si no existe, la experiencia corre sin sonido (aviso solo en consola).
- `images/terminal.jpg`: fachada del Terminal. Si existe, se integra de noche (virado, oscurecida, con máscara). Si no, se omite.
- Rutas y tiempos: `js/config.js`.
- Para ver una escena sin esperar, abre `index.html?t=30` (salta a los 30 s).
